# Hidden Mood

Web-based mental health self-assessment application using DASS-21, Indonesian sentiment analysis, Bi-LSTM, and weighted fusion methods.

## Features
- User authentication
- Curhat analysis
- DASS-21 assessment
- Weighted fusion result
- Dashboard visualization
- History tracking
- Feedback system

## Technologies
- Node.js
- Express.js
- Supabase
- Machine Learning API
- JavaScript
- HTML/CSS
